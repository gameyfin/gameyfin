# Security Policy

## Supported Versions

Only the latest stable release of Gameyfin is supported for security fixes.

| Version | Supported |
| --- | --- |
| Latest stable release | Yes |
| Older releases | No |
| Preview and prerelease versions | No |

Security fixes are delivered in new releases. We do not backport security fixes
to older versions. Upgrade to the latest stable release to receive fixes.

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately using
[GitHub's private vulnerability reporting form](https://github.com/gameyfin/gameyfin/security/advisories/new).

Do not disclose vulnerability details in public issues or discussions before
coordinating disclosure with the maintainers.

To help us investigate, include:

- The affected Gameyfin version and relevant deployment details or configuration.
- Steps to reproduce the issue or a minimal proof of concept.
- The expected behavior and the actual behavior.
- The potential security impact and any prerequisites for exploitation.

Redact credentials, access tokens, personal data, and other sensitive information
from reports, logs, and screenshots.

We review reports on a best-effort basis and communicate through the private
GitHub report. We cannot guarantee response times or fix deadlines. Please
coordinate publication with us until a fix or mitigation is available.
